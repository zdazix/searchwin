# SearchWin: сайт агентства AI search growth для B2B и SaaS

Главная страница агентства органического роста с фокусом на AI-поиск. Она сделана в формате визуального сторителлинга: вся страница рассказывает одну историю о том, как покупатель проходит путь от вопроса в ChatGPT до подписанного договора.

**Сквозной посыл:** мы не просто делаем бренд видимым в ИИ, а приводим оттуда лиды, звонки, демо, продажи и клиентов. Мы работаем только с B2B и SaaS.

---

## Как посмотреть

```bash
python3 -m http.server 8080
# открыть http://localhost:8080
```

Можно просто открыть `index.html` двойным кликом, но Chrome не грузит шрифты с `file://`, поэтому для честного просмотра лучше локальный сервер.

Полезный режим **`?ph`** (`http://localhost:8080/?ph`) подсвечивает оранжевой рамкой все места, где стоит временный текст или цифры, которые нужно заменить.

## Концепция и дизайн

- **Сюжет из пяти глав** повторяет путь покупателя: `01 Prompt → 02 Shortlist → 03 Visit → 04 Demo → 05 Deal`. Внизу экрана висит «док» с этапами: он подсвечивает, на каком этапе сейчас читатель, и всегда держит под рукой кнопку отчёта.
- **Мосты между главами:** вертикальная линия прорисовывается при скролле и переводит к следующей главе фразой курсивом. Так блоки читаются как одно повествование, а не как набор секций.
- **Цвет несёт смысл** во всей инфографике: синий означает видимость (упоминания, доля голоса), зелёный означает выручку (демо, пайплайн, сделки). Пары цветов проверены на различимость при дальтонизме.
- **Стиль:** от Superside взяты тёмные «лесные» панели со скруглением, шрифты Inter Tight + Instrument Serif (курсив для акцентных слов) и «радиоактивный» зелёный акцент. От Growmodo взяты светлые секции, крупные карточки, пилюли-кнопки и большой футер с вордмарком.

## Форма заявки

По умолчанию форма открывает почтовый клиент посетителя с готовым письмом на `hello@searchwin.com`, поэтому заявка не теряется молча. Чтобы заявки приходили автоматически, добавьте эндпоинт в `<form>`:

```html
<form class="form" data-form data-endpoint="https://formspree.io/f/XXXXXXX" novalidate>
```

Скрипт отправит `POST` с JSON `{ name, email, website, prompt }`. Подойдёт Formspree, Make/Zapier webhook, HubSpot через прокси или свой API.

## Где что редактировать

- **Тексты:** `index.html`, каждая секция подписана комментарием.
- **Сценарии чата в hero** (вопрос, ответ, уведомление, сумма сделки): массив `HERO_SCENARIOS` в `assets/js/main.js`.
- **Запросы в облаке:** `index.html`, секция `#prompt`. Класс `q--hot` выделяет запрос тёмным.
- **Цвета, шрифты, отступы:** `:root` в `assets/css/styles.css`.
- **Иконки:** SVG-спрайт встроен в начало `<body>` (`#i-openai`, `#i-gemini` и т. д.).

## AI- и SEO-готовность

Сайт агентства по AI-поиску сам должен хорошо читаться ИИ:

- семантическая разметка, один `h1`, JSON-LD (`Organization`, `ProfessionalService`, `WebSite`, `FAQPage`);
- `llms.txt` с кратким описанием агентства для языковых моделей;
- `robots.txt` явно открывает доступ GPTBot, OAI-SearchBot, PerplexityBot, ClaudeBot, Google-Extended и другим;
- `sitemap.xml`, Open Graph-картинка `assets/img/og.png`, favicon;
- шрифты на своём хостинге, без сторонних запросов; JS около 136 КБ без сжатия.

## Доступность и производительность

- `prefers-reduced-motion`: анимации и плавный скролл отключаются, облако запросов становится статичным.
- Без JavaScript весь контент виден.
- Видимый фокус с клавиатуры, ссылка «Skip to content», у графиков есть текстовые описания и подсказки при наведении и фокусе.
- Адаптив проверен на 1440 и 390 px. На телефоне текст сторителлинга идёт карточками поверх «прилипшей» инфографики.
