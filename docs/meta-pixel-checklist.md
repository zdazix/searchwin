# Meta Pixel: чек-лист настройки для аудиторий (searchwin.ai/ai-check)

Названия кнопок даны по русскому интерфейсу Meta, в скобках английские. Если пункта нет на месте, ищите по английскому названию: Meta часто переставляет меню.

## A. Включить пиксель на сайте

- [ ] **Events Manager** (business.facebook.com/events_manager) → слева «Источники данных» (Data sources) → ваш датасет **Searchwin data** → скопируйте **ID** (длинное число, у вас `1532183152066126`).
- [ ] **Vercel** → проект → Settings → Environment Variables → добавьте `PUBLIC_META_PIXEL_ID` = этот ID (для Production) → Save.
- [ ] Vercel → Deployments → у последнего деплоя меню «…» → **Redeploy**.
- [ ] Не добавляйте тег Meta в Google Tag Manager: пиксель уже ставится сайтом, иначе события задвоятся.

## B. Проверить, что события идут

- [ ] Events Manager → ваш датасет → вкладка **«Тестовые события»** (Test events).
- [ ] В поле «Адрес сайта» впишите `https://searchwin.ai/ai-check/` → «Открыть сайт» (Open website).
- [ ] На открывшейся странице нажмите **Accept** в баннере cookie (в Испании без этого пиксель не стартует) и подождите 3 секунды.
- [ ] В Test events должен появиться `PageView`.
- [ ] Введите тестовый сайт (например, реальный сайт любой местной компании): появятся `CheckStarted`, затем `ViewContent` (когда придёт результат).
- [ ] Оставьте свой email в форме аудита: появится `Lead` с параметром `kind = local`.
- [ ] Если ничего нет: отключите блокировщики рекламы (или откройте в окне инкогнито без расширений), поставьте расширение **Meta Pixel Helper** и посмотрите, что оно показывает. Адрес не должен содержать `?preview=1`.
- [ ] Вкладка «Диагностика» (Diagnostics): нет красных ошибок.

## C. Подтвердить домен

- [ ] Business Settings (Настройки компании) → **Безопасность бренда** (Brand Safety) → **Домены** (Domains) → «Добавить» → `searchwin.ai`.
- [ ] Выберите способ подтверждения (запись DNS TXT у регистратора домена, либо файл, либо метатег) и подтвердите.
- [ ] Свяжите домен с вашим рекламным аккаунтом и датасетом, если Meta это предложит.

## D. Настроить приоритет событий (Aggregated Event Measurement)

- [ ] Events Manager → датасет → **Настройки** (Settings) → «Настроить веб-события» (Configure web events) / «Приоритет событий».
- [ ] Выберите домен `searchwin.ai` и расставьте приоритеты:
  1. `Lead` — главное событие.
  2. `ViewContent`.
  3. `CheckStarted` (если Meta не даёт использовать своё событие для оптимизации, оставьте его только для аудиторий).
- [ ] Сохраните.

## E. Создать аудитории

Ads Manager или Events Manager → **Аудитории** (Audiences) → **Создать аудиторию** (Create Audience) → **Индивидуальная аудитория** (Custom Audience) → **Веб-сайт** (Website) → источник: ваш датасет. Названия давайте как в таблице.

| # | Название | Событие | Условие | Срок |
|---|---|---|---|---|
| 1 | `SW | Все визиты` | Все посетители сайта по URL (или `PageView`) | URL содержит `ai-check` | 30 дней |
| 2 | `SW | Ввели сайт` | `CheckStarted` | — | 30 дней |
| 3 | `SW | Увидели результат` | `ViewContent` | — | 30 дней |
| 4 | `SW | Заявка (email)` | `Lead` | — | 180 дней |
| 5 | `SW | Заявка local` | `Lead` | параметр `kind` равно `local` | 180 дней |
| 6 | `SW | Заявка online` | `Lead` | параметр `kind` равно `online` | 180 дней |

Для составных аудиторий (создаются через «Включить людей, которые соответствуют **любому** / **всем** условиям» и «Исключить»):

| # | Название | Включить | Исключить | Срок |
|---|---|---|---|---|
| 7 | `SW | Не ввели сайт` | `PageView` (URL содержит `ai-check`) | `CheckStarted` | 30 дней |
| 8 | `SW | Ввели сайт, но без email` | `CheckStarted` | `Lead` | 30 дней |
| 9 | `SW | Увидели результат, но без email` | `ViewContent` | `Lead` | 30 дней |

Что с ними делать:
- **#8 и #9** — основной ретаргетинг: люди почти дошли, нужен напоминающий креатив («Ваш полный аудит и дорожная карта ждут»).
- **#7** — «холодный» ретаргетинг, креатив про пользу проверки.
- **#4** — исключайте эту аудиторию из всех кампаний на привлечение, чтобы не платить за тех, кто уже оставил заявку.

## F. Look-alike (похожие аудитории)

- [ ] Дождитесь **100+ человек** в аудитории `SW | Заявка (email)` (лучше 300+).
- [ ] Audiences → Create Audience → **Похожая аудитория** (Lookalike) → источник `SW | Заявка (email)` → страна (США, Испания и т.д., по отдельной на страну) → размер **1%**.
- [ ] Позже добавьте 1–3% и сравните стоимость заявки.
- [ ] Если заявок мало, источником можно взять `SW | Увидели результат` (дешевле, но качество ниже).

## G. Первая кампания

- [ ] Цель кампании: **Лиды** (Leads) или **Конверсии** (Sales/Conversions) → событие оптимизации `Lead`.
- [ ] В целях/аудитории: добавьте look-alike и ретаргетинг (#8, #9), **исключите** `SW | Заявка (email)`.
- [ ] Для Испании и США делайте отдельные наборы объявлений: у них разные языки и страницы (`/es/ai-check/` и `/ai-check/`).
- [ ] В ссылках объявлений добавляйте метки `utm_source=facebook&utm_medium=paid&utm_campaign=...`: они придут в Telegram и в таблицу заявок.

## H. Что учесть

- **Cookie-баннер:** в ЕС в аудиторию попадают только согласившиеся с cookie. Аудитория из Испании будет заметно меньше трафика; это нормально.
- **Минимум:** Meta показывает рекламу на аудиторию от 100 человек.
- **Диагностика:** раз в неделю смотрите Events Manager → Диагностика и «Качество сопоставления событий» (Event Match Quality) для `Lead`.
- **Серверная отправка (Conversions API):** сейчас события идут только из браузера, часть людей (блокировщики, Safari/iOS) теряется. Если бюджет вырастет, стоит добавить серверный `Lead` (на странице уже есть `event_id` для дедупликации).
- **Приватность:** Privacy Policy на сайте описывает пиксель и баннер; покажите её юристу, особенно для Испании.
